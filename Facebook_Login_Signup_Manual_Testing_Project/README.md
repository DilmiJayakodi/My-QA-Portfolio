#  Facebook Login & Signup Manual Testing Project

##  Overview
This project contains manual testing documentation for Facebook Login and Signup functionalities, focusing on authentication flow validation using both positive and negative test scenarios.


## Objective
To verify the correctness and reliability of Facebook authentication features through structured manual testing.

TestPlan/
TestCases/

- Test Plan for Login & Signup modules  
- Manual Test Cases (Positive & Negative Scenarios)
